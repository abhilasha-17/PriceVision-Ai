**PriceVision AI 🏠📊**:
A Machine Learning project to predict house prices.

**✨ Features**:

✅ House Price Prediction using Machine Learning

✅ Data preprocessing + feature engineering

✅ K-Means clustering for grouping similar houses

✅ Streamlit UI for interactive predictions

✅ Saved models for fast inference (.pkl)

✅ Screenshots of results and UI included

**✨ What makes this project unique?**

1. Built using real housing data collected from Dehradun localities
2. Predicts house price based on BHK, area (sqft), furnishing, parking, water supply, gas pipeline, and landmark
3. Includes a Streamlit web app for real-time user input and prediction
4. End-to-end pipeline: data cleaning → feature engineering → model training → evaluation → deployment
